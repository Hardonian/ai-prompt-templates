## How to Use

1. Find the template category you need
2. Copy the template
3. Replace `[BRACKETS]` with your specific details
4. Paste into your AI tool
5. Iterate and refine

## Template Format

Each template includes:
- **Template:** The ready-to-use prompt
- **Variables:** What to customize (in [BRACKETS])
- **Example:** A filled-in example
- **Tips:** How to get better results
