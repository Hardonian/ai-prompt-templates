## How to Use Templates

### Step 1: Find Your Category

Browse the `templates/` folder or `agent-ops/` folder for the category you need:

- `templates/business-strategy.md` — Business and strategy prompts
- `templates/coding-development.md` — Coding and development prompts
- `templates/writing-content.md` — Writing and content prompts
- `templates/data-analysis.md` — Data and analysis prompts
- `templates/creative-ideation.md` — Creative and ideation prompts
- `templates/automation-agents.md` — Automation and agent prompts

### Step 2: Copy the Template

Each template is formatted as:

```
### Template Name

**Template:**
[Your prompt text here with [VARIABLES] in brackets]

**Variables:**
- [VARIABLE_1]: Description
- [VARIABLE_2]: Description

**Example:**
[Filled-in example showing how to use the template]

**Tips:**
- Tip 1 for better results
- Tip 2 for customization
```

### Step 3: Replace Variables

Replace all `[BRACKETED_TEXT]` with your specific details:

- `[INDUSTRY]` → "SaaS", "e-commerce", "healthcare"
- `[PRODUCT]` → "project management tool", "fitness app"
- `[AUDIENCE]` → "small business owners", "developers"

### Step 4: Paste and Run

Paste the customized prompt into your AI tool:
- ChatGPT (chat.openai.com)
- Claude (claude.ai)
- Gemini (gemini.google.com)
- Local LLMs (Ollama, LM Studio, etc.)

### Step 5: Iterate

Refine the prompt based on results. Adjust variables, add constraints, or modify the output format.

## Tips for Better Results

1. **Be specific** — Replace vague variables with concrete details
2. **Add constraints** — Specify output format, length, tone
3. **Include examples** — Show the AI what good output looks like
4. **Iterate** — Refine based on initial results
5. **Combine templates** — Use multiple templates in sequence
