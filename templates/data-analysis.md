# Data & Analysis Prompt Templates

## Data Analysis
```
Analyze this dataset and provide insights:

[PASTE DATA or DESCRIBE DATASET]

Provide:
1. Summary statistics (mean, median, mode, std dev)
2. Key trends and patterns
3. Outliers and anomalies
4. Correlations between variables
5. 3 actionable recommendations
6. Visualization suggestions (chart types)
7. Questions the data raises

Format: structured report with bullet points.
```

## Report Generator
```
Generate a [WEEKLY/MONTHLY/QUARTERLY] report for [METRIC/PROJECT].

Data points:
- [METRIC 1]: [VALUE]
- [METRIC 2]: [VALUE]
- [METRIC 3]: [VALUE]

Previous period: [VALUES]

Include:
1. Executive summary (3 sentences)
2. Key metrics dashboard
3. Trend analysis (vs previous period)
4. Wins and achievements
5. Challenges and risks
6. Recommendations (3-5)
7. Next period goals

Audience: [executives/team/clients]
Format: [bullet points/narrative/mixed]
```

## KPI Dashboard Design
```

Business type: [TYPE]
Goals: [LIST]
Current metrics tracked: [LIST]

Recommend:
1. Primary KPIs (3-5, with targets)
2. Secondary metrics (5-10)
3. Dashboard layout (sections)
4. Visualization types for each metric
5. Alert thresholds
6. Reporting frequency
7. Data sources

Tool: [Google Sheets/Tableau/Grafana/Custom]
```

## Trend Identification
```
Identify trends in [INDUSTRY/TOPIC] for [TIME PERIOD].

Consider:
- Technology trends
- Consumer behavior shifts
- Regulatory changes
- Competitive landscape
- Economic factors

For each trend:
1. Description
2. Evidence/signals
3. Impact level (high/medium/low)
4. Timeline (immediate/6-12 months/1-3 years)
5. Opportunity or threat
6. Recommended action
```
