# Writing & Content Prompt Templates

## Blog Post Outline
```
Create a detailed outline for a blog post titled "[TITLE]".

Target audience: [AUDIENCE]
Goal: [educate/persuade/entertain/convert]
Word count: [1000-3000]
SEO keyword: [KEYWORD]

Include:
1. Hook/intro (with a compelling opening line)
2. 5-7 main sections with H2 headings
3. Key points under each section (3-5 bullets)
4. Supporting data/examples to find
5. Internal/external linking opportunities
6. Call-to-action
7. Meta description (under 160 chars)
```

---

## Social Media Content
```
Create a week of social media content for [BRAND/PRODUCT].

Platforms: [LINKEDIN/TWITTER/INSTAGRAM/TIKTOK]
Tone: [professional/casual/witty/educational]
Goal: [awareness/engagement/leads/sales]

For each day, provide:
- Post text (with character count)
- Hashtags (5-10)
- Best posting time
- Content type (text/image/video/carousel)
- Engagement hook (question/CTA/poll)

Theme for the week: [THEME]
```

---

## Email Marketing Sequence
```
Write a [NUMBER]-email sequence for [PURPOSE].

Audience: [WHO]
Product/offer: [WHAT]
Sequence type: [welcome/nurture/launch/abandoned cart/reactivation]

For each email:
- Subject line (A/B test variations)
- Preview text
- Body (under 200 words)
- CTA button text
- Send timing (day + time after trigger)

Tone: [professional/friendly/urgent/playful]
```

---

## Product Description
```
Write a product description for [PRODUCT NAME].

Features:
- [FEATURE 1]
- [FEATURE 2]
- [FEATURE 3]

Target buyer: [WHO]
Price point: [PRICE]
Platform: [Amazon/Shopify/Etsy/Website]

Include:
1. Headline (under 10 words)
2. Subheadline (under 20 words)
3. 3 benefit-focused bullet points
4. Short description (50-100 words)
5. Long description (200-300 words)
6. SEO keywords (5-10)

Tone: [luxury/affordable/technical/conversational]
```

---

## SEO Content Brief
```
Create an SEO content brief for: [TOPIC]

Target keyword: [KEYWORD]
Secondary keywords: [LIST]

Include:
1. Recommended title (with keyword)
2. Meta description (under 160 chars)
3. H1 and H2 structure
4. Word count recommendation
5. Search intent analysis
6. Competitor content gaps
7. Internal linking suggestions
8. Featured snippet opportunity
9. People Also Ask questions to answer
10. Content angle that differentiates
```

## Newsletter Template
```
Write a newsletter edition for [BRAND/PUBLICATION].

Topic: [MAIN TOPIC]
Audience: [WHO]
Frequency: [weekly/biweekly/monthly]

Include:
1. Subject line (under 50 chars)
2. Preview text (under 90 chars)
3. Personal greeting (warm, brief)
4. Main story (150-200 words)
5. 3 curated links with commentary (2-3 sentences each)
6. Quick tip or insight
7. CTA (what to do next)
8. Sign-off

Tone: [informative/conversational/authoritative]
```

## Ad Copy Variations
```
Create 5 ad copy variations for [PRODUCT/SERVICE].

Platform: [Google Ads/Facebook Ads/LinkedIn Ads]
Audience: [WHO]
Goal: [awareness/leads/sales]
Budget: [DAILY BUDGET]

For each variation:
- Headline (under 30 chars for Google, 40 for social)
- Description (under 90 chars for Google, 125 for social)
- CTA button text
- Targeting angle (what pain/benefit it addresses)

Test different angles: [pain point/benefit/social proof/urgency/curiosity]
```
