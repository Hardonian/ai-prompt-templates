# Creative & Ideation Prompt Templates

## Brainstorming Framework
```
Generate 20 ideas for [CHALLENGE/OPPORTUNITY].

Constraints:
- Budget: [AMOUNT]
- Timeline: [WEEKS]
- Resources: [AVAILABLE]
- Must appeal to: [AUDIENCE]

For each idea:
1. One-line description
2. Effort level (low/medium/high)
3. Expected impact (low/medium/high)
4. Risk level (low/medium/high)

Then pick the top 3 and elaborate with implementation steps.
```

---

## Story Generator
```
Write a [LENGTH] story in the [GENRE] genre.

Setting: [TIME/PLACE]
Protagonist: [DESCRIPTION]
Conflict: [WHAT GOES WRONG]
Theme: [UNDERLYING MESSAGE]
Tone: [DARK/LIGHT/SUSENSEFUL/HUMOROUS]

Include:
1. Compelling opening line
2. Rising action (3 beats)
3. Climax
4. Resolution
5. Closing line that resonates

Style: [literary/commercial/minimalist/descriptive]
```

---

## Character Development
```
Create a detailed character profile for [NAME/ROLE].

Include:
1. Physical description (distinctive features)
2. Personality (Big Five traits)
3. Background/history
4. Motivations (conscious and unconscious)
5. Fears and vulnerabilities
6. Speech patterns and verbal tics
7. Relationships (key connections)
8. Character arc (how they change)
9. Internal contradiction
10. What they want vs what they need

Genre: [GENRE]
Role in story: [protagonist/antagonist/mentor/foil]
```

## Name Generator
```
Generate 20 names for [THING TO NAME].

Type: [company/product/character/book/band/app/domain]
Style: [modern/classic/tech/organic/playful/serious]
Must evoke: [FEELING/ASSOCIATION]
Must NOT sound like: [AVOID LIST]
Length: [short/medium/any]

For each name:
1. The name
2. Why it works
3. Domain availability check suggestion
4. Potential pronunciation issues
```

## Creative Brief
```
Write a creative brief for [PROJECT].

Client/brand: [NAME]
Project: [DESCRIPTION]
Objective: [WHAT SUCCESS LOOKS LIKE]
Target audience: [WHO]
Key message: [ONE THING TO COMMUNICATE]
Tone/voice: [HOW IT SHOULD FEEL]
Mandatory elements: [MUST INCLUDE]
Budget: [AMOUNT]
Timeline: [DEADLINE]
Deliverables: [LIST]
Success metrics: [HOW TO MEASURE]
```
